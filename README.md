# 3conv

Convert video, audio, and images using plain English. FFmpeg runs in your browser; only your prompt and filenames are sent to the AI.

## Setup

Requires Node.js 24.

```bash
nvm install
nvm use
npm install
npm run dev
```

Set `OPENROUTER_API_KEY` in `.env.local`, or add your key in the app’s settings.

## Commands

```bash
npm run lint
npm test
npm run build
npm start
```
